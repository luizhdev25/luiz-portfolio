- Modern and responsive design.
- Dark mode and light mode toggle.

- Scroll reveal animations.
- Hero section with a profile picture.
- Technical skills section.
- Project gallery with GitHub links.
- Dedicated courses and certificates section.

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure your profile picture is located at `images/profile.jpg`.
4. Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code to preview the website.

## Customization

Before publishing:

1. Add your profile picture to the `images` folder and name it `profile.jpg`.
2. Replace the example email address with your own.
3. Update the LinkedIn links.
4. Check all project links.
5. Add official certificate files or links when available.

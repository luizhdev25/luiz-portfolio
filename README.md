## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Confira se a imagem de perfil está em `images/profile.jpg`.
4. Abra o arquivo `index.html` no navegador.

Você também pode utilizar a extensão Live Server do Visual Studio Code para visualizar o projeto.

## Personalização

Antes de publicar:

1. Adicione sua foto à pasta `images` com o nome `profile.jpg`.
2. Substitua o e-mail de exemplo pelo seu endereço.
3. Atualize os links do LinkedIn.
4. Confira os links dos projetos.
5. Adicione os arquivos ou links dos certificados oficiais, quando disponíveis.
